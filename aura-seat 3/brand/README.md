# Brand assets

## Logo

| File | Use |
|---|---|
| `logo/01_mark_colour.png` | red seat, black frame — the primary, on cream |
| `logo/02_mark_black.png` | one-colour black — stamps, kraft, single-ink print |
| `logo/03_mark_cream.png` | one-colour cream — on red and on black |
| `logo/04_mark_white.png` | one-colour white — on photography only |
| `logo/05_mark_red.png` | one-colour red — on cream, sparingly |
| `logo/06–08_lockup_vertical_*.png` | mark above the wordmark |
| `logo/09–10_lockup_horizontal_*.png` | mark beside the wordmark |
| `logo/00_mark_*.svg`, `mark-original.svg` | vector, for print and web |

PNG files are transparent, 2048 px on the long edge.

Never stretch the mark, never add a stroke, shadow or gradient,
and never set the wordmark in anything but Jost caps at 340 tracking.

## Photography

`photography/` holds the four images used in the carousels — shopfront, business card,
app icon, umbrella. Each one appears as **slide 2** of its post, straight after the mark,
so the photograph is the hook and the graphics carry everything after it.

Treatment is fixed: cream tag top left, red code chip top right, one hairline
foot rule at the bottom with a caption. The image itself is never cropped to a
shape, never tinted, and never has the logo composited onto it.
