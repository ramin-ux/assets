# fortylove — LinkedIn

Пять каруселей по десять слайдов. 50 файлов, 1080 × 1350, sRGB, JPG.

```
fortylove-linkedin/
  post-a/  a-01.jpg … a-10.jpg     the mark
  post-b/  b-01.jpg … b-10.jpg     the kit
  post-c/  c-01.jpg … c-10.jpg     the court
  post-d/  d-01.jpg … d-10.jpg     print
  post-e/  e-01.jpg … e-10.jpg     the name
  texts.md            тексты постов и первые комментарии
  plan.json           план заливки в Buffer
  set-links.py        подставляет боевые ссылки в plan.json
  check-links.sh      проверяет все 50 ссылок
  CHECKLIST.md        что проверено
  contact-sheet.jpg   все 50 слайдов одной картинкой
```

## Порядок слайдов внутри поста

01 знак на плоском фоне · 02 фото · 03 кадр с кортом и сеткой слов · 04 фото ·
05 палитра · 06 бокал на корте · 07 графическая страница или фото ·
08 графическая страница · 09 фото · 10 фото.

Слайдов с локапом нет, нумерации в углах нет.

## Заливка

1. Положить папку `fortylove-linkedin` целиком в корень публичного репозитория.
   **Имя папки не менять и не ставить пробелы** — иначе ссылки станут ломкими,
   а при переименовании все старые отдадут 404.

2. Подставить свои ссылки:

   ```
   cd fortylove-linkedin
   python3 set-links.py <user> <repo> main
   ```

3. Проверить, что всё отдаётся:

   ```
   bash check-links.sh
   ```

   Должно быть «200 OK: 50 из 50». Пока не так — в Buffer не заливать.

4. Закоммитить обновлённый `plan.json` обратно в репозиторий.

## Заливка в Buffer

`get_account` → `list_channels` → взять точный channelId LinkedIn. Дальше на каждый пост:

```
create_post(channelId, schedulingType="automatic", saveToDraft=true,
  text=<текст>, assets=<10 объектов image>,
  metadata={"linkedin": {"firstComment": "<призыв и 5 хештегов>"}})
```

В объекте ассета только `url`. Alt-текст не заполнять нигде.
Хештеги только в первом комментарии, в тексте поста символа `#` быть не должно.

## Проверка после заливки

Пять черновиков, у каждого ровно 10 ассетов, ни у одного ассета нет altText,
дублей нет, ничего не опубликовано.
