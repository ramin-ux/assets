# fortylove — весь пакет для LinkedIn

Всё готово к ручной загрузке. Публикацию делаешь сам, ничего никуда не отправляется автоматически.

```
carousels/          пять постов-каруселей, по 10 слайдов
  post-a … post-e   1080 x 1350, JPG, порядок задан именами файлов
  texts.md          текст поста и первый комментарий для каждого
  contact-sheet.jpg все 50 слайдов одной картинкой для быстрой проверки
collages/
  static/           четыре бренд-борда, 1280 x 1104, JPG
  video/            четыре анимированных борда, 1080 x 1080, 60 fps, H.264
    posters/        первый кадр каждого видео, если нужна обложка
  texts.md          текст поста и первый комментарий для каждого
```

## Как загружать

Карусель: в LinkedIn выбрать «Add a document» не нужно — грузишь 10 изображений
из папки поста в том порядке, в каком они лежат. Формат 1080 x 1350 подходит и
для ленты Instagram.

Коллаж: один пост — один файл. Либо статичный борд из `static/`, либо видео из
`video/`. Видео зациклено, первый и последний кадр совпадают, звука нет.

Хештеги во всех текстах — ровно пять, первый всегда `#raminnasibov`, и они идут
только в первый комментарий, не в тело поста.

## Что поменялось в этой версии

Все текстовые карточки в коллажах теперь несут элемент айдентики: план корта,
струнную сетку 16 на 19, линию сетки со счётом или рамку зоны подачи. Простого
текста на плашке не осталось. Линии везде волосяные — толщина считается от
ширины самого чертежа, а не от высоты карточки, поэтому ничего не выглядит
жирным. Статичные борды и видео пересобраны с этими карточками.
