## Specs

- Carousel slides: 1080 x 1350, sRGB, JPG quality 93, 8 slides per post, 5 posts.
- Collages: 1280 x 1104. Three PNG, three MP4.
- Video: H.264, yuv420p, 60 fps, 5 s, no audio. The build finishes inside the first 45 percent,
  the board then holds still. Drift and pulse use a whole number of periods so the loop is invisible.

## Type

Display and headline: Inter Display, Light to Semibold.
Labels and captions: Inter, Regular and Medium, letterspaced.

## Palette

PORCELAIN #F6F4F2 / LIMEWASH #EEE6E0 / MIST #A6ABBF / DUSTY BLUE #8A9BAD / DEEP INK #46586B

The palette is presented differently on every post and every board: full width bars, dots on a light
band, paper chips, vertical planes, squares, circles, stripes, a code list with a marker.
